TravelNest - booking near your adventurers made easy

TravelNest is a personal project inspired by a conversation with my dad while we were planning a trip to Chicago. We wanted to stay somewhere that was roughly central to all the places we wanted to visit — and that sparked the idea.
TravelNest lets you input any locations you plan to visit and then suggests nearby hotels or Airbnbs based on the average location of those places. It’s a simple tool to help make trip planning smarter and more efficient.
The project is still a work in progress — in the future, I’d love to add the ability to view popular attractions directly on the map and easily add them to your list.

Campus Life App

Campus Life is a school project where we were assigned to create a web application that addresses common pain points in college life through a unified interface.

The project requirements:

  • Three or more HTML pages using semantic HTML to organize content.

  • Custom CSS with responsive rules and layout techniques.

  • Bootstrap integration for styling and responsive components.

  • JavaScript interactivity using event-driven programming to enhance user experience.

  • One or more external APIs, integrated to display live or dynamic content (e.g., events, maps, menus, news, etc.). We suggest using a free API from this list of free public APIs.

  • Accessibility features that meet WCAG standards (semantic structure, alt text, color contrast, etc.).

  • Responsive design that works well on desktop, tablet, and mobile.

  • Deployed website using GitHub Pages with all linked files working as expected.

Wireframes were created in Procreate
